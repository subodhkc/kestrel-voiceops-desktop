# Kestrel VoiceOps Desktop Application

Desktop application for Kestrel VoiceOps - A native voice operations platform with Twilio integration.

## Features

- Native performance with Electron
- System tray integration
- Offline support
- Twilio Voice SDK integration
- Real-time call management
- SMS inbox
- Call history
- AI mode controls
- Contact lookup

## Download

Download the latest installers from [GitHub Releases](https://github.com/subodhkc/kestrel-voiceops-desktop/releases).

### Windows
- Download `Kestrel VoiceOps Setup 0.1.0.exe`
- Run the installer
- Follow the installation wizard

### macOS
- Download `Kestrel VoiceOps-0.1.0.dmg`
- Mount the DMG file
- Drag KestrelVoice to Applications
- Launch from Applications

## Development

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build:windows  # Windows
npm run build:mac      # macOS
```

## Security Notice

This desktop application is not code-signed. You may see a security warning from Windows or macOS during installation. This is normal for unsigned applications.
